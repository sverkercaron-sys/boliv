# BoLiv

Sveriges mest kompletta plattform för hem och boende.

BoLiv består av:

- **BoLiv Guider** – kunskap om att bygga, renovera, underhålla, köpa, sälja och bo bättre.
- **Mitt BoLiv** – digital fastighetspärm, underhållsplan, projekt och dokument.
- **BoLiv Partner** – exklusiva företagsplatser per tjänstekategori och kommun.

## Teknik

- Next.js
- TypeScript
- Supabase
- Vercel

Projektet är under uppbyggnad.
